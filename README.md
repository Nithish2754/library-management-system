# Library Management System

The Library Management System is a database-driven application developed as part of a DBMS project. The system provides a frontend interface connected to a relational database to efficiently manage library records such as books, users, and transactions.

This project demonstrates the practical implementation of database concepts along with a structured and user-friendly frontend.

---

## 📚 Features

- Add, update, and delete book records
- Maintain student and user information
- Issue and return books
- Store and retrieve data using a relational database
- User-friendly and responsive frontend interface

---

## 🛠️ Technologies Used

- HTML5  
- CSS3  
- JavaScript  
- MySQL  
- SQL

---

## 🗄️ Database Design

The database is designed using relational principles and normalization techniques. It consists of multiple tables to store information related to books, users, and book transactions. Primary keys and foreign keys are used to maintain data integrity and relationships between tables.

---

## 🎯 Project Objective

The objective of this project is to apply DBMS concepts such as database design, normalization, and SQL queries in a real-world application. It also focuses on integrating a frontend interface with a database to perform CRUD operations effectively.

---

## ⚙️ System Workflow

1. Users interact with the frontend interface to manage library operations.
2. User actions trigger SQL queries for data insertion, update, retrieval, or deletion.
3. The database processes the queries and stores the information securely.
4. The updated data is reflected in the frontend.

---

## 🔮 Future Enhancements
